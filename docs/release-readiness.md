# Условия готовности релиза

## Android

- Анализ, тесты, подпись и проверка идентификатора пакета должны пройти.
- Обновление устанавливается поверх предыдущей версии UserNet и сохраняет аккаунт, профиль и настройки.
- На телефоне проверяются привязка, прямой режим, ручной Fabric, контрольный и рабочий звонки, полезный HTTPS-трафик, остановка и повторный запуск.
- Отдельно проверяются Wi-Fi, мобильная сеть и повторные переключения в обе стороны в автоматическом и принудительном звонковом режиме. Во время восстановления проверяется остановка пользователем.
- Мобильная проверка проводится без Wi-Fi, включая длительную фоновую нагрузку и смену сети. Запущенный контейнер и зелёный короткий тест не заменяют эту проверку.
- Проверяется доступность каждого рекламируемого выхода. Неудачный тест требует диагностики, а не объявления ноды исправной.
- Первый вход при блокировке API пока не поддерживается; описание продукта должно сообщать это ограничение.

## Windows

Нужны отдельная сборка установщика, проверка обновления, подписи, иконки и обычной работы Mihomo. Android-адаптер звонков на Windows не реализован: нельзя обещать такую же устойчивость к блокировкам.

## Публикация

Сначала публикуется версионный APK, затем атомарно обновляется манифест. Перед выпуском проверяются актуальные артефакты и результаты мобильного тестирования. Лицензионные обязательства при распространении сохраняются.

## Ограничения

Производительность звонкового транспорта зависит от сети и оператора. Короткая проверка соединения не подтверждает длительную устойчивость; перед массовым выпуском необходимы повторяемые мобильные тесты трафика, простоя и смены сети.
