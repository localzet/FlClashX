## Аккаунт

Если подписка уже импортирована, на вкладке «Аккаунт» выберите
«Подключить аккаунт текущей подписки». Повторно копировать ссылку не нужно.
Это привязывает существующую подписку к устройству; платную покупку не выполняет.
Можно также вставить свою ссылку вручную. Старый внутренний порт 2053 удаляется
перед обращением к публичному HTTPS-сервису.

Первый вход требует доступного API. При повторном входе клиент может использовать
сохранённый доступ к звонковому транспорту. Токены и транспортные настройки
хранятся в защищённом хранилище Android. Перехваченная HTML-страница и ошибка
шлюза не считаются успешной проверкой API.

## Маршрут и сервисы звонков

На вкладке «Аккаунт» доступны три режима:

- **Автоматически**: прямой маршрут с переходом на звонковый при повторных сбоях.
- **Прямой**: звонковый транспорт выключен.
- **Через звонок**: используется выделяемый звонковый транспорт.

Сервис контрольного звонка и сервис транспортного звонка выбираются отдельно.
В режиме «Через звонок» отсутствие рабочего туннеля не переводит трафик
незаметно на прямой маршрут.

Ручной выбор сохраняется после перезапуска и не заменяется другим провайдером
при неудачном подключении. Недоступные для аккаунта провайдеры не выбираются.
«Авто» использует доступные настройки подписки.

Кнопка «Подключить транспорт» включает звонковый режим. Сам транспорт может
работать для API аккаунта и без включённого VPN; чтобы маршрутизировать трафик
приложений, необходимо также включить VPN на главной вкладке.

## Состояния

Контрольный звонок аутентифицирует устройство и запрашивает рабочую сессию.
После её выделения контрольный звонок завершается — это штатный переход.
Затем устанавливается отдельный транспортный звонок для передачи данных.

Зелёный статус рабочего туннеля появляется только после события его подключения.
Выделенная сессия или работающий процесс не являются доказательством доставки
трафика в Интернет. При восстановлении соединения статус меняется обратно
на подключение. Кнопка остановки отменяет текущую попытку и отключает VPN, если он был включён.
Это также прекращает периодические попытки восстановить транспорт.

Анимация орбиты работает во время подключения и работы туннеля. Системное
отключение анимаций учитывается. Настройки доступны и из карточки на главной.

## Проверка выпуска

Проверять на физическом Android через мобильную сеть с выключенным Wi-Fi:
вход по существующей подписке, прямой режим, ручной звонковый режим,
контрольная и рабочая стадии, внешний HTTPS-запрос, остановка и повторный запуск.
Проверка внешнего запроса должна идти через выбранный туннель, а не только
через API или работоспособность сервера. Не публиковать ссылки подписок,
ключи сессий, токены, cookies и адрес панели управления.

VK требует настроенного peer id и cookies на входной ноде. API должен
рекламировать только настроенные рабочие провайдеры; до завершения настройки
VK доступен Телемост.

При недоступности API сохранённая привязка аккаунта не превращается в форму регистрации: экран сообщает о сохранённой привязке и предлагает повторить запрос.

Зелёный статус рабочего туннеля выдаётся после HTTPS-запроса к API через звонковый SOCKS. Проверяется TLS обычным Android trust store и корректный JSON; ошибка проверки не выдаётся за подключение.

## Проверки выходных нод через звонковый транспорт

В звонковом режиме минимальный тайм-аут проверок групп и провайдеров — 30 секунд: вложенное TLS-соединение через видеотранспорт может занимать больше стандартных 3 секунд. Более длинный тайм-аут подписки сохраняется. Проверки выполняются лениво с интервалом 3600 секунд, чтобы не перегружать общий канал параллельными проверками. В прямом режиме эти параметры подписки не изменяются.

Успешный отдельный запрос и зелёный индикатор не доказывают устойчивость всего VPN. Перед выпуском нужны длительные проверки автоматического выбора выхода, ручного выбора ноды, работы в фоне и смены мобильной сети.

На установление контрольного и рабочего звонков вместе с проверкой HTTPS отводится до двух минут. Ограничение относится ко всей попытке; остановка пользователя прерывает её через проверку поколения. Медленный, но продвигающийся запуск не должен отменяться через 45 секунд.
