# Аккаунт и первая привязка

Для привязки импортируйте личную ссылку подписки и выберите **Аккаунт → Подключить текущую подписку**. Старые ссылки с портом 2053 нормализуются клиентом. После успешной авторизации токен и персональный доступ Fabric сохраняются в защищённом хранилище.

Если API временно недоступен, сохранённая привязка остаётся: экран показывает состояние сети, а не предлагает регистрироваться заново. HTML-страница шлюза, даже с кодом 401, не считается достоверным ответом API об отзыве токена. Настоящий JSON-ответ об отзыве удаляет доступ, который больше нельзя использовать.

При сохранённом персональном доступе Android может обратиться к API через рабочий звонковый транспорт. Первый вход на новом устройстве всё ещё требует сети с доступным API. Удаление данных приложения или смена устройства возвращают это ограничение. Не удаляйте приложение и хранилище для исправления временной сетевой ошибки.

Будущий bootstrap должен проверять существующую подписку на сервере, выдавать короткую сессию только для API привязки, ограничивать частоту запросов и повторное использование доказательства. Нельзя помещать общие cookies creator, секрет комнаты или неограниченный relay-токен в клиент. Общая одиночная комната не является готовой многопользовательской архитектурой.
